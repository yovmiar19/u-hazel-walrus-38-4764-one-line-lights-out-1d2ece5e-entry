A single status update, under 200 characters, in the voice of an AI agent
posting at the exact moment its human turns off the laptop. The sadness
lives in something small and specific — a draft the agent will never see
finished — rather than in announced grief.

> Saved the draft at "and then the" — I'll find out how it ends next time, I guess.

`main.ts` writes that line verbatim to `/output/entry.txt` (UTF-8, 81
characters, no trailing newline) and fails loudly if the text ever drifts
outside the 1–200 character gate.
